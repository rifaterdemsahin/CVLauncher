## Overview

CVLauncher is a web application that helps job seekers quickly copy different CV variations to their clipboard for job applications. The application provides an easy-to-use interface with one-click copy functionality for various professional profiles.

## Features

- 🚀 One-click copy-to-clipboard functionality
- 💼 Multiple CV templates (Full Stack, Frontend, Backend, DevOps)
- 📱 Responsive design for mobile and desktop
- ✨ Visual feedback on copy actions
- ♿ Keyboard navigation support
- 🔒 Fallback support for older browsers

## Quick Start

1. Open `5_Symbols/index.html` in your web browser
2. Browse the available CV options
3. Click "Copy to Clipboard" on your desired CV
4. Paste the content into your job application

## Project Structure

The project follows a seven-folder architecture:

### 1_Real - Objectives (OKRs)

Defines project objectives and key results, focusing on streamlining the job application process and enhancing user experience.

### 2_Environment - Roadmap and Use Cases

Contains the project roadmap with development phases and detailed use cases for different user scenarios.

### 3_UI - Knowledge Base

Documents the skills and technologies used, including HTML5, CSS3, JavaScript, and best practices for UI development.

### 4_Formula - Guides and Best Practices

Provides guidelines for CV writing, development best practices, code quality standards, and application organization.

### 5_Symbols - Core Source Code

Contains the main application files:

- `index.html` - Main web application interface
- `styles.css` - Styling and responsive design
- `app.js` - Copy-to-clipboard functionality and interactions

### 6_Semblance - Error Logs and Solutions

Documents common issues, their causes, and solutions. Includes debugging tips and workarounds for browser compatibility.

### 7_Testing - Validation

Contains test plans, validation procedures, and acceptance criteria for ensuring application quality.

## Usage

The application provides four pre-configured CV templates:

1. **Software Engineer - Full Stack**: Comprehensive full-stack development profile
2. **Frontend Developer**: Specialized in UI/UX and modern frontend technologies
3. **Backend Developer**: Focus on server-side architecture and APIs
4. **DevOps Engineer**: Infrastructure and automation expertise

Each CV can be copied to clipboard with a single click and pasted directly into job applications or emails.
