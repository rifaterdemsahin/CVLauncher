# Use Cases

## Use Case 1: Quick CV Response
**Actor:** Job Seeker
**Goal:** Quickly copy a tailored CV for a job application
**Steps:**
1. Open CVLauncher web application
2. Browse available CV variations
3. Select appropriate CV for the job type
4. Click copy button
5. Paste into job application or email

## Use Case 2: Multiple Job Applications
**Actor:** Active Job Seeker
**Goal:** Apply to multiple jobs with different CV variations
**Steps:**
1. Access CVLauncher application
2. Identify job types (e.g., Frontend, Backend, Full-stack)
3. Copy relevant CV for each application
4. Track which CV was used for which application

## Use Case 3: CV Maintenance
**Actor:** Career Professional
**Goal:** Update and maintain multiple CV versions
**Steps:**
1. Review existing CV templates
2. Update skills and experience
3. Test copy functionality
4. Verify formatting is maintained
