**Purpose:** Static CV repository. Serves 93 tailored PDF CVs generated from `source_Cv.md`.
The `public/index.html` is regenerated by running `python3 generate_index.py` and redeploying.

**Key routes:**
- `/` — CV grid index with Download + Copy Link buttons per card
- `/<filename>.pdf` — Direct PDF download (e.g. `/cv_ai_platform_engineer.pdf`)

### 2. rifat-cvs-response-generator
| Key | Value |
|-----|-------|
| **URL** | https://rifat-cvs-response-generator.fly.dev/ |
| **Recruiter page** | https://rifat-cvs-response-generator.fly.dev/recruiter |
| **Status** | Deployed |
| **Region** | ams (Amsterdam) |
| **Stack** | Node 18 + Express |
| **Source** | `5_Symbols/response_generator/` |
| **Config** | `5_Symbols/response_generator/fly.toml` |
| **VM** | shared-cpu-1x, 512 MB RAM |
| **Port** | 8080 (internal) |
| **Secrets** | `XAI_API_KEY` (set via `fly secrets set`, sourced from Doppler `cvlauncher/dev`) |
| **Auto-stop** | Yes (cold-starts on request) |
| **Min machines** | 0 |

**Purpose:** AI-powered recruiter response tool. Takes a recruiter message, reads the master CV
(`Source/cv.md`), fetches live CV links from `rifat-cvs.fly.dev`, and calls xAI Grok-3 to
generate a tailored reply with a matching CV link included.

**Key routes:**
- `/recruiter` — Three-panel UI: recruiter input | source CV viewer | generated response
- `/api/respond` (POST) — Generates response via Grok-3; returns `{ response, links, debug }`
- `/api/cv` (GET) — Returns raw CV markdown for the in-page CV panel

**UI features:**
- Copy Response button
- Show Prompt button (reveals full prompt sent to Grok-3)
- Debug panel (shows API key status, CV load status, error detail)

## Doppler Configuration

| Key | Value |
|-----|-------|
| **Project** | `cvlauncher` |
| **Config** | `dev` |
| **Dashboard** | https://dashboard.doppler.com/workplace/5ccb59c6d72db414f3e7/projects/cvlauncher/configs/dev |
| **Secrets managed** | `XAI_API_KEY` |

Secrets are pushed to Fly.io manually with:
```bash
fly secrets set XAI_API_KEY="$(doppler secrets get XAI_API_KEY --project cvlauncher --config dev --plain)" \
  --app rifat-cvs-response-generator
```

```bash
# Deploy response generator
cd 5_Symbols/response_generator
fly deploy
```
